# PertFold_CellPatch

在 VCC 2025 H1 数据上预测 CRISPRi 基因扰动的表达反应，面向 VCC 2026。

**当前版本：`z2`（2026-10-23）**　·　各版本的结果与改动见 [HISTORY.md](HISTORY.md)

## 模型
z2 = **kNN 与 PertFold3 Z1 模型的等权混合**，在打分空间预测全部表达基因上的变化 δ。
- **kNN（不训练）：** 从 STRING ≥ 0.7、K562 Perturb-seq、DepMap 三个来源各取前 5 个训练扰动（并集最多 10 个），平均它们的真实反应。
- **Z1 模型：** r4-v2 的网络主体（CellPatch encoder + cell / pert MSA + nbw 证据 decoder），从 r4-v2 的阶段 1 权重出发，重新训练阶段 2：
  - 输出对照中表达的全部基因（13,275 个），直接在打分空间（伪 bulk log1p）预测；
  - loss：全基因单细胞 ZINB + 弱 DE 分类（0.1）+ 邻居打分 loss + 对照重构（空扰动重构对照细胞）；
  - 1000 步，每 25 步按 val PDS 代理选权重；推理时供体 = 全部非测试扰动。
- **混合：** δ = 0.5·kNN + 0.5·c·(Z1 − 0.25·训练平均)，c = 两者预测范数比的中位数；整体幅度 s 交叉拟合（选到 3）。

## 当前结果
5 折交叉验证（全部 147 个扰动），全部表达基因。指标是 VCC 2026 的六项（cell-eval，5 次重复），↑ 越高越好，↓ 越低越好；综合分以 identity 为 0、真实数据对半自比为 1。

| 方法 | PDS↑ | MSE↓ | fidelity↑ | reach↑ | sig_jacc↑ | lfc_nmae↓ | 综合分↑ |
|---|---|---|---|---|---|---|---|
| PIE（Arc，官方配方） | 待测 | | | | | | |
| kNN（不训练，三来源并集） | 0.646 | 3.260 | 0.476 | 0.391 | 0.070 | 0.893 | 0.194 |
| A-E 线性（K562 表征，Nat Methods 2025） | 0.533 | **2.714** | 0.442 | 0.352 | 0.028 | 1.018 | 0.072 |
| Z1 模型（五种子集成） | 0.637 | 3.035 | 0.471 | 0.364 | **0.084** | **0.827** | 0.211 |
| **z2：kNN + Z1 混合** | **0.674** | 3.823 | **0.501** | **0.401** | 0.072 | 0.854 | **0.226** |

- z2 相对 kNN：综合分 +0.031，逐扰动 95% 置信区间 [+0.015, +0.050]，显著；5 折全部更高。
- 所有方法的 MSE 都高于 identity（1.019），这一项在综合分里计 0。
- 旧版本（r4）只预测 2,125 个基因，与本表口径不同，见 HISTORY.md。
